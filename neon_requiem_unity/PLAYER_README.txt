NEON REQUIEM / GHOSTS IN THE RAIN
This file is for the Windows player AFTER a successful real Unity build.
The source ZIP is NOT a playable Windows game.

Extract the whole player ZIP. Keep NeonRequiem.exe, UnityPlayer.dll,
NeonRequiem_Data and MonoBleedingEdge together. Run NeonRequiem.exe.
No Unity Editor is needed by a successfully built player.

WASD move; mouse look; Shift sprint; Ctrl crouch; Space jump.
E interact; Q jam a nearby active drone; Esc pause/back.
At the cipher: A/D choose, Enter submit. The service placard has the order.
F12 saves an actual screenshot under the game's persistent data Screenshots folder.

Mission: west market broker, three service relays, listening machine,
security override, amber stair, skyline transmission.
Use crates and crouch to break the drone's line of sight. Q jams it for
five seconds; the jammer recharges in twelve seconds. Restart after death.

Graphics: Medium/High/Ultra in the title or pause menu.
This source's final appearance and performance have not been tested.
Windows runtime validation must be performed on the actual compiled build.
