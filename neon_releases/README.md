# NEON VEIL downloads

- [Standalone Windows x64 ZIP](https://github.com/fahedfifi24-FAHEDFIFI11/BLENDER/raw/refs/heads/neon-veil-godot45/neon_releases/Neon_Veil_Windows.zip)
- [Editable Godot 4.5 project and Blender kit](https://github.com/fahedfifi24-FAHEDFIFI11/BLENDER/raw/refs/heads/neon-veil-godot45/neon_releases/Neon_Veil_Source.zip)

Extract the Windows ZIP and run **NeonVeil.exe**. No editor installation is needed.
WASD move, mouse look, Shift sprint, Ctrl crouch, E interact, Esc pause.

The binary embeds the game data. The package includes all exported runtime files,
launch instructions, license notices, and an actual in-game screenshot. Checksums are
in `SHA256SUMS.txt`. Native Windows execution was unavailable; source and embedded-export
functional checks ran with Linux Godot. See the project's validation report for limits.
