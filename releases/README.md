# Ashen Hollow downloads

- [Windows game ZIP](Ashen_Hollow_Windows.zip): extract and run `AshenHollow.exe`.
- [Complete Godot source ZIP](Ashen_Hollow_Source.zip): extract and import `AshenHollow/project.godot` with Godot 4.6.3.

On a GitHub ZIP file page, choose **Download raw file** to download it. Both archives contain real files, not Git LFS pointers.

The default renderer is Forward+. An optional compatibility launcher is included in the Windows archive. The source project, controls, screenshots and validation report are also browsable in [ashen_hollow](../ashen_hollow/README.md).

The project passed 110 automated checks. The exported embedded game content passed 51 integration checks on Linux. Windows export succeeded; native Windows runtime testing remains outstanding.
