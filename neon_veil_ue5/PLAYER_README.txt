NEON VEIL / GHOST SIGNAL

This file describes the Windows game produced AFTER a successful UE 5.4 build.
The source archive itself is not a playable Windows build.

Extract the COMPLETE packaged game ZIP. Run NeonVeil.exe.
Keep Engine, NeonVeil/Binaries and NeonVeil/Content/Paks beside the launcher.
Install the included Engine/Extras/Redist/en-us prerequisite installer if required.
Target: Windows x64, DirectX 12 compatible modern dedicated GPU, 1080p.

WASD move | Mouse look | Shift sprint | Ctrl crouch | Space jump
Right mouse aim | Left mouse fire | R reload | E interact | Esc pause

Find Ivo in the sunken market. Press E to advance his dialogue.
Use the corporate gate terminal. Find the security console and align three pulses:
press E while the pulse is in the cyan band. Misses lose one lock; leaving cancels.
Defeat five security units. Marksmen telegraph shots; breachers close for melee.
Use solid cover: camera aim and muzzle traces both respect walls.
Take the illuminated east stair to the rooftop and use the extraction terminal.
A shopfront archive offers an optional recovery patch.

Main/pause menus provide Low / Medium / High / Epic presets and master volume.
Death restarts the mission. No persistent saves or controller bindings are included.
Native Windows playtesting and performance validation are required after packaging.
